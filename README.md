## 🛠️ Projects:

- **Automated Translator Assessment Platform (Phraze)**  
  Built an end-to-end system that generates Excel-based translation tests from YouTube videos (yt-dlp, ffmpeg, Express.js, Python), reducing screening time by ~80–90%. Implemented an AI grading agent + RAG contextualization engine (LangChain, Llama-3-70B, ChromaDB) achieving 90%+ agreement with human evaluators and producing rubric-based feedback across grammar, style, and cultural fit.

- **Semantic Similarity–Based Dynamic Pruning (SSDP) for Tree-of-Thought (Algoverse AI Research)**  
  Designed an inference-time optimization that reduces redundant exploration by 85–90%, lowers token usage by 45%, and cuts end-to-end latency by 35% on GSM8K and MATH500. Combined with tree attention, KV caching, memory compression, and early stopping to run 8B models on 10GB GPUs with 38% cost savings.

- **Hybrid Database for Twitter Analytics**  
  Built a hybrid database system combining structured, semi-structured, and graph data to process and store 138,601 tweets. Implemented caching mechanisms that reduced search latency by 99.99% for user and tweet lookups.

- **Customer Churn Prediction (Dataiku, End-to-End Deployment)**  
  Built and deployed a full churn prediction system in Dataiku: automated ingestion, visual prep, feature engineering, and models (Logistic Regression, Random Forest, Gradient Boosting). Delivered a production scoring pipeline with explainability, risk segmentation (High/Medium/Low), and executive dashboards to enable proactive retention strategies.

- **Language Model Pipeline for Text-to-SQL (Lang2Query)**  
  Developed a text-to-SQL pipeline using baseline and fine-tuned Mistral with LoRA + RAG, evaluated using BLEU/ROUGE/BERTScore. Integrated FAISS-based retrieval and memory optimizations to improve query accuracy over baselines.
